## نبذة

VEXYON برنامج لويندوز بيشغّل نماذج الذكاء الاصطناعي على جهازك أنت، عن طريق [Ollama](https://ollama.com)، وبيفهرس الملفات اللي تختارها ويجاوب عن محتواها بالعربي أو الإنجليزي — من غير ما ملفاتك تتبعت لأي سيرفر.

وغير المحادثة، المساعد بيستخدم أدوات: يقرا ويدوّر في الملفات، يتعامل مع إكسل، يشغّل بايثون للحسابات الدقيقة (بموافقتك)، يدوّر على البرامج المثبّتة، ويفتكر تفضيلاتك.

## المميزات

- 🔒 **أوفلاين وخصوصية كاملة** — الفهرس والمحادثات والإعدادات والذاكرة في `%AppData%\VEXYON` ومفيش حاجة بتترفع.
- 💬 **واجهة عربية بالكامل (RTL)** مع زرار 🧠 تفكير عميق للأسئلة الصعبة.
- 📚 **مكتبة شخصية** — بيراقب فولدر (`Documents\MyBrain`) ويفهرس PDF وWord وExcel والنصوص في قاعدة SQLite محلية.
- 🧰 **أدوات للنموذج** — قراءة وبحث وإنشاء وتعديل الملفات، قراءة إكسل، تشغيل بايثون وأوامر، البحث عن برامج، وغيرها.
- 🧮 **حسابات متحقَّق منها** — مكتبتين (`vexyon_math` و`vexyon_calc`) للرياضة والكمرات والمقاطع، مع 22 اختبار دقة والتحقق من الحل بالتعويض.
- 🧠 **ذاكرة طويلة المدى ودروس** — تعليمات دائمة، وذاكرة تقدر تعدّلها، وقواعد قصيرة بيتعلمها من الأخطاء المصحَّحة.
- 🌐 **بحث إنترنت اختياري** — مقفول افتراضياً، وكل عملية بتتسجّل في `audit.log`.
- 📊 **شريط أداء حي** — المعالج والرام وكارت الشاشة وحرارة المعالج.
- 🛠 **تبويب الأدوات** — بيكتشف البرامج المثبّتة ويوفّر تحميل أدوات مفيدة بضغطة.
- 💾 **نسخ احتياطي واسترجاع** لبيانات البرنامج.
- 🎨 **وضع داكن وفاتح.**
- 🛡 **آمن افتراضياً** — الأوامر والأكواد لا تُنفَّذ إلا بموافقتك.

## التحميل

نزّل أحدث ملف **`VEXYON-v*-win-x64.zip`** من صفحة [Releases](../../releases) (أو من *Artifacts* في أي تشغيل في [Actions](../../actions)). جواه:

```
VEXYON.exe                 ← جاهز للتشغيل، من غير تثبيت .NET
README.md / README.ar.md
EULA.txt
THIRD_PARTY_NOTICES.txt
docs/                      ← الشعار والصور والملاحظات
source/                    ← ملفات المشروع كاملة
```

> ويندوز SmartScreen ممكن يحذّر لأن الملف غير موقّع رقمياً.

## المتطلبات

- ويندوز 10 / 11 (64 بت)
- رام 8 جيجا أو أكتر (يفضّل)
- حوالي 5 جيجا للنماذج
- Ollama (زرار تحميل جوه البرنامج)
- إنترنت **مرة واحدة** لتنزيل النماذج، وبعدها كله أوفلاين
- بايثون 3 (اختياري لأدوات الحسابات)

## ابدأ بسرعة

1. شغّل `VEXYON.exe` — تبويب **ابدأ هنا** هيوريك الخطوات.
2. ثبّت Ollama من الزرار جوه البرنامج.
3. دوس **تنزيل النماذج** (`qwen3:4b` للمحادثة و`bge-m3` للفهرسة).
4. حط ملفاتك في `Documents\MyBrain`.
5. افتح **المحادثة** واسأل.

## البناء من الكود

محتاج [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0):

```bat
Build.bat          :: بناء وتشغيل سريع
BuildRelease.bat   :: exe مستقل + ملف تثبيت (لو Inno Setup 6 متثبّت)
```

أو افتح `VEXYON.csproj` في Visual Studio واضغط **F5**.

### البناء التلقائي على GitHub

ملف `.github/workflows/build.yml` بيبني المشروع مع كل push ويطلّع ملف zip (فيه الـ exe وملفات المشروع) تنزّله من **Actions ← آخر تشغيل ← Artifacts**. ولو عملت tag مثل `v1.1.0` بيترفع تلقائياً كـ Release:

```bash
git tag v1.1.0 && git push origin v1.1.0
```
